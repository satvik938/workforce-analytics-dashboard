About this dashboard: data, metrics and method
Business question
Where are we losing people, how fast are we replacing them, and which teams need retention attention?
Data
~590 synthetic employee records (hire and exit dates, department, salary, engagement) for a mid-size distribution company. Created for this portfolio; no real people.
Turnover rate
Separations in the period ÷ average headcount in the period.
Days to fill
Days from requisition opening to accepted offer, averaged over hires in the period.
Engagement
Average pulse-survey score on a 1–5 scale for active employees.
Method
Python (pandas) to build monthly snapshots from event dates; KPI logic mirrors SQL window functions; visualized with D3.

Recommended actions from this view: run stay interviews in Customer Service and Warehouse (lowest engagement), review shift scheduling and supervisor ratios in Operations, and pre-build talent pipelines for IT and Finance where roles take 30+ days to fill.

Portfolio project built with Python (pandas) and D3.js · All data is synthetic. Source code and data are in this repository.
